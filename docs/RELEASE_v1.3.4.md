# v1.3.4 — Android onboarding demo, design tokens

The responsive native-art demo, now wired to the Figma design tokens. This release is built from the `main` source at this tag. Motion, audio and layout are those of [v1.3.3-R](https://github.com/namvunhatle/r15-onboarding-android-demo/releases/tag/v1.3.3-R), and so is the picture.

## Downloads

| APK | Renderer | Application ID |
| --- | --- | --- |
| **A7-Compose-1.3.4.apk** | Jetpack Compose | `namvunhatle.r15.onboarding.compose.responsive` |
| **A7-XMLViews-1.3.4.apk** | XML Views | `namvunhatle.r15.onboarding.views.responsive` |

Both are debug APKs for review and require Android 9 / API 28 or later. They update 1.3.3-R in place (same application ID, `versionCode` 2) and install beside the `v1.3.3-native` and `v1.3.3` builds. `SHA256SUMS.txt` lists the APK checksums; `THIRD_PARTY_NOTICES.txt` accompanies their bundled third-party assets.

## What changed

- **Design tokens.** Colours, type, corner radii and spacing reference the ZEN variables bound in the A7 frames. 154 variables are exported read-only from Figma and generated into `ZenTokens.kt` (Kotlin, Figma paths kept, for example `Zen.Color.Background.Accent.Solid.Default`) and `zen_tokens.xml` (`@color/zen_*`, `@dimen/zen_*`). The ad SDK kit's variables are kept apart as `AdKit`.
- **Visual-only values, listed separately.** Some values Figma draws without a variable: splash art, glow sizes and blurs, gradient angles, shadows, device chrome and the ad's progress bar. These are the only raw colours in the code, in `A7Visual.kt` / `a7_visual.xml`.
- **Kept from v1.3.3.** A few v1.3.3 values stay where Figma now binds a different token, so the demo stays 1:1. Each is listed with the token that production should use.
- **Pixel check.** On an API 36 emulator at 1080 × 2400, 34 screenshots across both apps differ from 1.3.3-R by at most 1/255 per channel. That is the token opacities replacing hand-rounded ones. Both apps built, and both lint tasks completed with 0 errors.

See [Design tokens](https://github.com/namvunhatle/r15-onboarding-android-demo/blob/v1.3.4/docs/DESIGN_TOKENS.md) for the pipeline, the token map, and the visual-only table. See the [changelog](https://github.com/namvunhatle/r15-onboarding-android-demo/blob/v1.3.4/CHANGELOG.md) for earlier versions.

## Known limits

- Phones only, about 16:9 to 23:9. Tablets and landscape are still letterboxed.
- Not tested on physical devices, foldables or in multi-window.
- The token snapshot is regenerated by hand (`export_tokens.js` → `gen_tokens.py`), not synced from Figma.
- Replay during a destination transition, time inspection of the final scene, and partial reduced motion behave as in earlier releases. Ads, purchases and destinations are mocked.
